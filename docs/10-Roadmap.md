# Roadmap

Work top to bottom. Each milestone has an owner-approved scope, a narrow sequence of PRs and exit evidence. Keep unfinished contracts visible in [progress](tracking/PROGRESS.md). The [implementation playbook](19-Implementation-Playbook.md) defines the steps and gates.

| Milestone | Scope | Exit evidence |
| --- | --- | --- |
| M0 | Rust workspace, build contract, diagnostics and ADRs | Native CI builds and executable smoke tests on five targets |
| M1 | Determinism, evidence harness and measurement | Seeded fixtures, injected failures and machine-readable reports |
| M2 | Renderer and platform feasibility | Native smoke coverage and real GPU captures per backend |
| M3 | Registries, terrain streaming and save foundation | Boundary determinism, cancellation and crash recovery |
| M4 | First playable settlement | Explore, harvest, build, power beacons, survive a night and reopen |
| M5 | Original content, accessibility and resilience | Coverage for each approved feature and an end-to-end player test |
| M6 | Cooperative play, packs and module SDK | Reconnect, compatibility, deterministic ordering and independent examples |
| M7 | Integration, regression closure and platform QA | Full declared coverage with reviewable gaps and minimum OS evidence |
| M8 | Signed distribution where required and maintenance | Checked artifacts, license inventory, release notes and rollback drill |
