# ADR-0001 · Original runtime and evidence first

**Status** · Accepted in the foundation handbook

Use safe first-party Rust, original WGSL and an owned renderer. Consider wgpu for GPU abstraction and winit for windowing after native feasibility tests. Establish an independent simulation, a small CPU reference mesher, bounded worker contracts and reproducible tests before expanding content. Preserve game rules across reference and enhanced presentation profiles.

The tradeoff is more foundation work before content expansion and a smaller early playable release. Revisit graphics dependencies and boundaries after M2 platform evidence. Keep original UI, lore, art and fixtures under documented provenance.
