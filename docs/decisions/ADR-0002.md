# ADR-0002 · Native build verification in GitHub Actions

**Status** · Accepted in the foundation handbook

Build and verify every declared Rust target on a matching GitHub-hosted runner. Use the committed lockfile, an exact Rust release and SHA-pinned Actions. Report handbook validation separately from runtime compilation while the workspace is absent. Use a single required check covering the entire matrix.

A cross-compiler alone would leave target runtime tests unverified. Native lanes increase runner usage and require monitoring labels and toolchains. GPU certification remains a distinct gate. Promote only artifacts built for the reviewed commit.
