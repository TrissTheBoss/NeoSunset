# Security policy

NeoSunset currently distributes a development handbook. Supported runtime versions will be listed here once releases exist.

Use the repository's [private vulnerability reporting page](https://github.com/TrissTheBoss/NeoSunset/security/advisories/new) when available. If private reporting is disabled, open a brief public issue asking the maintainers for a private contact channel. Share affected commits, impact, minimal reproduction and platform details privately. Remove credentials, player data, local paths and third-party files from reports.

See [security and asset handling](docs/14-Security-Assets.md) for project requirements.
