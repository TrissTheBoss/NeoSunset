# NeoSunset 0.1.0-alpha.1

First public alpha for Minecraft Java Edition 26.3. Use Java 25 and see the README for the loader versions exercised by this build.

- An opt-in Video Settings toggle preserves normal presentation until the client is focused with Unlimited FPS, VSync off and an eligible mod profile.
- OpenGL skips surplus swap calls against the active display's reported refresh rate. Vulkan prefers Mailbox where supported.
- GitHub Actions verifies the package, deterministic swap policy and client startup, option persistence, and finite-cap fallback before uploading this release.

The client checks use a Linux software renderer. Physical display cadence, driver-level FPS caps, memory use in long gameplay sessions, and third-party modpack behavior require separate testing. Unverified mod profiles retain ordinary presentation.
