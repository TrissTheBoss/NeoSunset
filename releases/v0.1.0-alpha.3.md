# NeoSunset 0.1.0-alpha.3

- Adds an in-game FPS and present-attempts overlay. Present attempts do not measure what the monitor actually displayed.
- Adds **NeoSunset: Frame rate overlay** to Video Settings. It is on by default, saves its own setting and does not affect refresh-aware presentation.

This alpha targets Minecraft Java 26.3 on Java 25. Publication requires the Java build, policy tests, JAR verification and Linux software-rendered smoke checks on Fabric, Quilt, Forge and NeoForge for the tagged commit. Those checks do not establish native GPU cadence, display scanout or restart behavior on a hardware-rendered client.
